# AI Study Planner

A machine learning-powered study planner that predicts how many hours you actually need per subject and allocates your study time based on difficulty, deadline, and importance.

---

## What It Does

You input details for up to 15 subjects. The app uses a trained ML model to predict the study hours needed for each subject, then builds a prioritized daily study plan.

**Inputs per subject:**
- Subject name
- Difficulty (1–5)
- Importance (1–5)
- Hours available per day
- Days until deadline
- Previous score (0–100)
- Study type: Theory / Conceptual / Practical

**Outputs:**
- Predicted hours needed per subject
- Priority-based time allocation
- Visual bar chart of study distribution
- Day-by-day study plan
- AI suggestions (flags low scores, high difficulty, urgent deadlines)

---

## How the Model Works

The model is a **Random Forest Regressor** trained to predict `actual_hours_needed`.

**Features used:**
- `difficulty`
- `hours_available`
- `deadline_days`
- `importance`
- `study_type` (encoded: Theory=1, Conceptual=2, Practical=3)
- `previous_score`
- `priority_score` = `(difficulty × importance) / deadline_days` ← engineered feature

Time allocation across subjects is then weighted by each subject's `priority_score` relative to the total.

## Setup & Installation

**Requirements:** Python 3.8+

### 1. Clone the repo

```bash
git clone https://github.com/anikameenuak/aistudyplanner.git
cd aistudyplanner
```

### 2. Install dependencies

```bash
pip install streamlit scikit-learn pandas
```

### 3. (Optional) Retrain the model

If you want to retrain from scratch instead of using the pre-built `model.pkl`:

```bash
python aistudyplanner.py
```

### 4. Run the app

```bash
streamlit run app.py
```

Open your browser at `http://localhost:8501`

## Limitations

- The model is trained on **synthetic data** generated by `generate_dataset.py` — not real student study patterns. Predictions may not reflect actual behavior.
- `study_history.csv` is appended locally every time you generate a plan. It is not deduped or user-specific.
- No authentication or multi-user support.
- No `requirements.txt` is included in the repo — you need to install dependencies manually.
